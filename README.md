# VitalQR — Emergency Medical ID

An emergency medical identification platform that helps make essential medical information and emergency contact details accessible through a scannable QR code.

### 💻 Source Code

### Key Features
- Digital medical profile
- Emergency contact information
- QR code generation
- Offline medical summary

### Tech Stack
Next.js · React · TypeScript · Supabase

Built as a student project to explore technology for emergency medical identification.
